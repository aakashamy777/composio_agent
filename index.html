02 — The Agent

How the 100 were actually researched

Not hand-filled. A four-stage pipeline: Composio's own toolkit registry first, Gemini + search grounding as fallback, automatic retry on failure, human patch for what both couldn't reach.

STAGE 1
Composio registry lookup
For each app, try composio.toolkits.get() directly. Ground-truth data: real auth scheme, tool count, category — no LLM guessing.
56 apps · agent-only
STAGE 2
Gemini + search grounding
Not in Composio's registry → Gemini researches the live docs URL, returns structured JSON: auth, self-serve/gated, API surface, verdict, evidence link.
21 apps · agent-only
STAGE 3
Automatic retry + backoff
23 apps failed on first pass — free-tier rate limits (429) and one JSON parse error. Retry script with exponential backoff cleared 21 of them automatically.
21 recovered · needed re-run
STAGE 4
Human patch
2 apps hit a hard daily quota wall even after key rotation (Mermaid CLI, Grain). Researched and entered by hand from their actual docs.

05 — Honesty

Where the agent got it wrong, or defeated me

  • △Auth fragmentation: first pass returned 70 distinct auth-method strings for what normalizes to ~5 real patterns. Fixed with a post-hoc normalization pass, not a better prompt — the model's raw categorization instinct is too granular to trust directly.
  • △"Unknown — check docs" fallback: Composio-registry apps sometimes don't expose a clean self-serve/gated signal in the SDK response, so ~6 of the registry-sourced apps in a 15-app sample fell back to a placeholder. That's a real gap in the registry data, not the agent inventing an answer.
  • △Gemini free-tier quota: 23/100 apps failed on the first full run from rate limits (20 requests/day free tier) plus one malformed-JSON response. Retry + backoff recovered 21; 2 (Mermaid CLI, Grain) needed a fresh API key and were still hand-verified rather than trusted blind.
  • △Sandbox vs. production nuance: the one verified miss (Plaid) shows the agent's weak spot — it correctly identifies the auth mechanism but sometimes collapses "free sandbox" and "gated production" into a single self-serve/gated verdict.
